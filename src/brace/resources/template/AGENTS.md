# Project agent instructions

- Treat `requirements.md` and `plan.md` as the project contract.
- Follow the exact task or bug assignment supplied by the coordinator.
- Work only inside the assigned worktree and allowed paths.
- Do not edit `.codex/state.json`, `.codex/tasks.json`, `.codex/bugs.json`, `requirements.md`, or `plan.md`.
- Do not push, merge, create pull requests, or modify remote state. The coordinator owns integration.
- Run the assigned focused checks and report only commands actually executed.
- Create one focused commit for the assigned task or bug.
- Follow the additional role prompt supplied by the coordinator.
