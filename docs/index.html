Three stages. One controlled path.

Agents do the reasoning and implementation. Brace owns scheduling, validation, integration, and recovery.

Built for unattended work

Parallel agents.
Shared control.

Brace keeps agents isolated while the coordinator enforces one consistent repository history.

{01}

Isolation by default

Builders, fixers, and project amendments operate in separate external Git worktrees. Agents never write over one another.

{02}

Provider-backed integration

Task and bug branches merge through real GitHub or Azure DevOps pull requests—not hidden local merges.

{03}

Drift stops the line

Brace checks repository, contract, branch, commit, ledger, and pull-request identities before critical transitions.

{04}

Recovery is state, not memory

Immutable assignments and results make interrupted work reconcilable without inventing progress or repeating completed steps.

{05}

People own scope

Operational failures retry within bounds. Semantic blockers surface an evidence-backed recommendation for your decision.

Git is the boundary

Every piece of work has an address.

No shared agent checkout. No ambiguous commit. No direct agent merge to main.
